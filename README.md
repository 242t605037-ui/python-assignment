# Python Assignment

A collection of Python programs created as part of a programming assignment, covering basic concepts and problem-solving.

## 📌 Project Overview

This project contains several beginner-friendly Python programs designed to practice fundamental programming concepts and improve problem-solving skills.

## 🚀 Programs Included

1. **Even or Odd** – Checks whether a number is even or odd.
2. **Largest Number** – Finds the largest among three numbers.
3. **Sum of Numbers** – Calculates the sum from 1 to a given number.
4. **Multiplication Table** – Displays the multiplication table of a number.
5. **Factorial** – Calculates the factorial of a given number.
6. **Menu-Driven Program** – Allows the user to select and run different programs.
